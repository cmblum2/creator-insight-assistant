Comment intent — regex vs sarcasm-aware LLM

The buy-intent filter is a cheap regex that reads keywords literally, so it counts sarcasm ("let me add to cart another $40 brush I don't need") as a real buy signal. The LLM classifier reads tone. Try a sarcastic comment. Eval: regex mislabels 5/10 sarcastic comments as intent; the LLM cuts that to 0/10, sarcasm detection 100% (eval/eval_sarcasm.py).
